# Ansible

Ansible is a powerful open-source automation platform that manages configuration, deploys applications, and orchestrates tasks without requiring agents on managed hosts. It operates over SSH, describes desired state in human-readable YAML playbooks, and is built on a large library of modules, making it one of the most widely used configuration management and automation tools.

Official documentation: <https://docs.ansible.com>

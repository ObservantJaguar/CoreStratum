# Configuration Management

Configuration management covers tools for automating the setup and maintenance of operating systems, services, and applications at scale. The category includes the agentless automation platform Ansible, the high-performance SaltStack, and the classic agent-based declarative systems Puppet and Chef.

- [Ansible](ansible.md) — agentless automation system that operates over SSH.
- [SaltStack](saltstack.md) — high-performance platform for remote execution and configuration management.
- [Puppet](puppet.md) — classic declarative, agent-based infrastructure management system.
- [Chef](chef.md) — automation tool using a programmatic Ruby DSL to describe systems.

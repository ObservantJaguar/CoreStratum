# Cloud-Init

Cloud-Init is the industry-standard open-source utility for automating the initial configuration of cloud instances during first boot. It processes user data and instance metadata to set hostnames, users, SSH keys, network configuration, and run scripts, enabling consistent, reproducible bootstrapping across a wide range of cloud and virtualization platforms.

Official documentation: <https://cloudinit.readthedocs.io>

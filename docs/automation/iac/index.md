# Infrastructure as Code

Infrastructure as Code (IaC) covers tools for declaratively defining, provisioning, and managing infrastructure resources and cloud environments. The category includes the Terraform ecosystem and its fully open fork OpenTofu, the general-purpose IaC platform Pulumi, and Cloud-Init for the automated initial configuration of cloud instances.

- [Terraform](terraform.md) — the industry standard for provisioning infrastructure through configuration files.
- [OpenTofu](opentofu.md) — fully open fork of Terraform created to preserve license purity.
- [Pulumi](pulumi.md) — IaC platform that describes infrastructure in general-purpose programming languages.
- [Cloud-Init](cloud-init.md) — industry standard for automated initial configuration of cloud instances.

# OpenTofu

OpenTofu is a fully open-source, community-driven fork of Terraform created to preserve an open license for infrastructure as code after the original project's licensing changes. It is broadly compatible with the Terraform provider and module ecosystem while remaining governed openly, making it a license-clean alternative for declarative infrastructure provisioning.

Official documentation: <https://opentofu.org>

# Cobbler

Cobbler is a Linux installation server that automates the deployment and provisioning of operating systems, both bare-metal and virtual. It provides network-based installation via PXE booting, integrates DHCP, DNS, and TFTP services, and uses profiles and repositories to simplify and standardize OS installation across a large number of machines.

## Key features

- Network installation via PXE with integrated DHCP, DNS, and TFTP
- Profile- and system-based definitions for repeatable installs
- Repository management and mirroring for installation sources
- Kickstart templating and automated post-install configuration

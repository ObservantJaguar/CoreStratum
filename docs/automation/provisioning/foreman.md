# Foreman

Foreman is an open-source, lifecycle management tool for physical and virtual servers that automates provisioning, configuration, and reporting. It handles bare-metal and virtual machine provisioning through integration with DHCP, DNS, and TFTP, and pairs with configuration management tools such as Puppet, Ansible, and Salt to keep systems in the desired state across their full lifecycle.

## Key features

- Bare-metal and virtual provisioning with integrated DHCP, DNS, and TFTP
- Host lifecycle management from provisioning to decommissioning
- Integration with Puppet, Ansible, Chef, and Salt
- Role-based access control and reporting

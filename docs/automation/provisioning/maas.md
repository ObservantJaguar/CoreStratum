# MAAS

MAAS (Metal as a Service) is an open-source tool from Canonical that enables the automated provisioning of physical bare-metal servers as if they were cloud instances. It manages the lifecycle of physical machines, including discovery, commissioning, deployment, and recycling, with network-based booting and a web and API-driven workflow for on-demand bare-metal.

## Key features

- Bare-metal provisioning with cloud-style on-demand workflows
- Automatic hardware discovery and commissioning
- Network-based booting with DHCP, DNS, and PXE management
- Integration with Juju, Ansible, and other automation tools
- Web UI and comprehensive REST API

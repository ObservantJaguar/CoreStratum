# HashiCorp Vagrant

HashiCorp Vagrant is a command-line tool for building and managing disposable development environments. It provisions reproducible virtual machines and containers on top of providers such as VirtualBox, VMware, Hyper-V, and Docker, using a single portable Vagrantfile, and is used to create isolated, consistent development environments matching production configuration.

## Key features

- Portable Vagrantfile describing the full environment in one file
- Works across VirtualBox, VMware, Hyper-V, Docker, and more
- Reproducible boxes and provisioners for consistent setups
- Easy team sharing of environment definitions via version control

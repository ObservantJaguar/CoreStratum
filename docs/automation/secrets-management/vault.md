# HashiCorp Vault

HashiCorp Vault is an open-source platform for centralized secret management, providing secure storage, dynamic generation, and controlled access to secrets such as passwords, API keys, and certificates. It focuses on strong encryption of data at rest, fine-grained access policies, audit logging, and secret rotation, making it a de facto standard for managing secrets in production environments.

## Key features

- Encrypted key-value storage with automatic secret versioning and lease management
- Dynamic secrets for databases, cloud providers, and services
- Multiple authentication backends including tokens, LDAP, OpenID Connect, and Kubernetes
- Fine-grained access policies and comprehensive audit logging
- Encryption-as-a-service through a transit secrets engine

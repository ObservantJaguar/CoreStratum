# Consul

HashiCorp Consul is a service networking platform that provides service discovery, health checking, secure service-to-service communication, and a distributed key-value store. Its KV store and leader-based coordination make it a reliable source of truth for configuration and state shared across a fleet of services and clusters.

## Key features

- Service discovery with dynamic, DNS and HTTP-based lookup
- Distributed key-value store for shared configuration and state
- Health checking and automatic service health-based routing
- Leader election and multi-datacenter federation
- Secure service mesh communication via Connect

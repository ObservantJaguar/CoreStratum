# ClamAV

ClamAV is an open-source antivirus engine used to scan mail gateways, file servers and uploads for malicious content. It detects a wide range of malware, including viruses, Trojans and phishing payloads, and is commonly integrated into spam-filtering pipelines. Its command-line tools and daemon mode make it easy to embed into larger mail and file-processing stacks.

# Claws Mail

Claws Mail is a lightweight and fast email client built on the GTK+ toolkit. It emphasizes speed, stability and configurability while providing a comprehensive feature set including filtering, multiple accounts, encryption support and plugin extensibility. Claws Mail is an excellent choice for users who prefer a minimal but complete desktop mail client.

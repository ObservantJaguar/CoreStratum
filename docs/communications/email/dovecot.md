# Dovecot

Dovecot is a high-performance open-source server for IMAP and POP3 access to mailboxes. It is designed for security and reliability, with support for Maildir, mailbox encryption, simple clustering and easy integration with mail delivery agents. Dovecot is widely deployed as the standard access layer of self-hosted mail infrastructure.

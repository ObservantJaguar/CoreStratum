# Email Infrastructure

A self-hosted mail stack is built from independent components: a mail transfer agent (MTA), a delivery and access server, filter engines and web mail clients. This category covers the server and client tools needed to run autonomous mail nodes, manage delivery, and filter spam and viruses.

- [Postfix](postfix.md) — reliable and high-performance mail transfer agent (MTA).
- [Exim](exim.md) — flexible mail server (MTA) with powerful routing.
- [Dovecot](dovecot.md) — high-performance server for IMAP and POP3 access.
- [Rspamd](rspamd.md) — fast mail filtering system based on neural networks.
- [ClamAV](clamav.md) — antivirus engine for scanning mail gateways.
- [Roundcube](roundcube.md) — popular web interface for mailboxes.
- [RainLoop](rainloop.md) — modern and fast web mail client.
- [Claws Mail](claws-mail.md) — minimal and fast client based on GTK+.

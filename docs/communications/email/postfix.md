# Postfix

Postfix is a reliable and high-performance mail transfer agent (MTA) designed for security, speed and ease of maintenance. Combined with a delivery agent and filters, it forms the heart of a full self-hosted mail server. Its modular design and clean configuration language make it the default choice for delivering large volumes of mail.

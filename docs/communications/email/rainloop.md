# RainLoop

RainLoop is a modern, fast and lightweight web mail client with a clean user interface. It supports the full IMAP/SMTP workflow, multiple accounts, contacts and strong theming capabilities while remaining simple to install and self-host. RainLoop is a good alternative when a speed-optimized webmail front end with a small footprint is required.

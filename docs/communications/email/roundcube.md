# Roundcube

Roundcube is a popular browser-based web interface for accessing email mailboxes. It offers a familiar desktop-like experience with message composition, folders, contacts and address-book integration, all backed by a modern extensible plugin system. Roundcube is broadly deployed alongside self-hosted mail servers as a full-featured webmail front end.

# Rspamd

Rspamd is a fast and scalable mail filtering system that uses statistical analysis and neural-network heuristics to classify messages as spam or ham. It integrates with mail transfer agents through the Milter protocol and provides a rich web interface for inspecting and tuning filtering rules. Rspamd combines high throughput with detailed, explainable scoring of every message.

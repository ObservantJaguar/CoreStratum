# Federated Social Networks

Federated social networks (the Fediverse) are decentralized alternatives to corporate media platforms, built on the ActivityPub protocol and interconnected through federation. Because the protocol is open and servers interoperate, users of any instance can follow and interact with users of every other instance. This category covers software for microblogging, media sharing and community discussion.

- [Mastodon](mastodon.md) — federated microblogging platform.
- [Pixelfed](pixelfed.md) — federated image sharing.
- [PeerTube](peertube.md) — decentralized video hosting.
- [Funkwhale](funkwhale.md) — federated music streaming.
- [Lemmy](lemmy.md) — federated link aggregator and forum.

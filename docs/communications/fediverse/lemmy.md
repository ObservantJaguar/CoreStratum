# Lemmy

Lemmy is a federated link aggregator and discussion forum that operates as a decentralized alternative to link-sharing platforms. Similar to a message board, it organizes content into communities where users can post links and start text discussions, with voting and moderation per community and per instance. Via ActivityPub, Lemmy instances interact with one another and with other Fediverse platforms.

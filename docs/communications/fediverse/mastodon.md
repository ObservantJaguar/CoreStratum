# Mastodon

Mastodon is a free, open-source microblogging platform that operates as a federated alternative to commercial social networks. Each instance is independently administered, while the ActivityPub protocol connects it to the wider Fediverse. Mastodon provides timelines, boost and favorite actions, media support and a full range of moderation tools.

# Pixelfed

Pixelfed is a federated image-sharing platform that serves as an open alternative to commercial photo-sharing services. Built on the ActivityPub protocol, it lets users run their own instance while remaining connected to the wider Fediverse. Pixelfed emphasizes visual content, private sharing options and community-controlled moderation.

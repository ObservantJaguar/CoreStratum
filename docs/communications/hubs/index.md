# Self-Hosted Hubs

Self-hosted hubs are comprehensive platforms for collaboration and office functions that bring file management, project management and document editing into one sovereign environment. This category covers integrated file and collaboration ecosystems as well as the office suites that power real-time joint document editing.

- [Nextcloud Hub](nextcloud.md) — industry-standard hub with Deck, Talk and Files modules.
- [ownCloud Infinite Scale](owncloud.md) — high-performance platform written in Go.
- [Pydio Cells](pydio-cells.md) — Go-based platform with advanced RBAC access control.
- [OpenProject](../../engineering/pms/openproject.md) — powerful open-source project management platform.
- [OnlyOffice](onlyoffice.md) — collaborative document editing engine.
- [Collabora](collabora.md) — online office suite for real-time document collaboration.

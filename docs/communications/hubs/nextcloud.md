# Nextcloud Hub

Nextcloud Hub is the de facto standard for self-hosted file and collaboration infrastructure. It combines file synchronization and sharing with integrated modules such as Deck for project boards, Talk for video conferencing and Files for storage and access management. As a fully self-hosted platform, Nextcloud gives organizations complete control over their files and collaboration data.

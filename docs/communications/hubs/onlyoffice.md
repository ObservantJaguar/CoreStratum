# OnlyOffice

OnlyOffice is an open-source office suite whose document editors support real-time, multi-user collaborative editing. It is frequently embedded in file-hosting platforms such as Nextcloud and ownCloud to provide on-the-fly document, spreadsheet and presentation editing. OnlyOffice offers both an integration component for existing hubs and a full suite of desktop and mobile editors.

# ownCloud Infinite Scale

ownCloud Infinite Scale (oCIS) is a high-performance, modern file sync and share platform rewritten in Go. It decouples storage, metadata and front end into scalable services, delivering strong performance and a simpler deployment model than its predecessor. Interested organizations can build a sovereign document hub with full control over data access and sharing.

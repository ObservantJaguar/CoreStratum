# Pydio Cells

Pydio Cells is a modern self-hosted file sharing platform written in Go and built around a microservices architecture. It provides an advanced role-based access control (RBAC) system, granular permissions and a web and mobile interface for managing files and user workspaces. Pydio Cells is suited to organizations that need fine-grained control over file access without resorting to commercial SaaS.

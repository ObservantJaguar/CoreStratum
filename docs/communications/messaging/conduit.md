# Conduit

Conduit is a lightweight Matrix homeserver that ships as a single binary, which makes it easy to deploy on small servers and even embedded systems. It focuses on low resource usage and simple operations while remaining compatible with the standard Matrix client-server API. Conduit is ideal for running a Matrix server with minimal hardware requirements.

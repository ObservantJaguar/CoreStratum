# Coturn

Coturn is an open-source TURN and STUN server used to enable WebRTC traffic to traverse NATs and firewalls. It relays media between peers that cannot connect directly, which is essential for reliable audio and video calls. Coturn also supports TURN over TLS/DTLS, making it a key component of any self-hosted real-time communications stack.

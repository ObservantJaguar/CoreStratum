# Dendrite

Dendrite is a second-generation Matrix homeserver written in Go, designed to be more efficient and scalable than its predecessors. It runs as a set of composable microservices that can be collapsed into a single process for simpler deployment. Dendrite is a strong choice for operators who want a modern, performant Matrix server with a smaller footprint.

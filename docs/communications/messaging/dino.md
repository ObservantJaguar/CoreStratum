# Dino

Dino is a modern native XMPP client for Linux, built on the GTK toolkit with a focus on clean design and ease of use. It supports OMEMO end-to-end encryption, group chats, file transfer, and voice and video calling. Dino brings a polished, desktop-native experience to federated XMPP messaging.

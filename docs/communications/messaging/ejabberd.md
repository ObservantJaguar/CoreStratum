# ejabberd

ejabberd is a robust and scalable XMPP messaging server written in Erlang, designed for high concurrency and distributed operation. It supports clustering across nodes, mobile push notifications, and a wide range of XMPP extensions for group chat and file transfer. ejabberd is a proven foundation for running large, reliable instant-messaging services.

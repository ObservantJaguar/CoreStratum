# Element

Element is the official multiplatform client for the Matrix protocol, available for web, desktop and mobile. It provides a full messaging experience including end-to-end encrypted chats, group rooms, file sharing and integration with bridged services. Element is the standard gateway that lets users connect to self-hosted and federated Matrix homeservers alike.

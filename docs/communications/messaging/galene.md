# Galene

Galene is a lightweight selective forwarding unit (SFU) server for WebRTC, written in Go and designed for lectures and live broadcasts. It emphasizes simplicity and ease of deployment while still supporting large rooms, recording, and audio and video selection. Galene is a good fit for self-hosted teaching and event streaming where minimal overhead matters.

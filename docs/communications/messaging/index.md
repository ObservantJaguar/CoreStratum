# Decentralized Messaging

Decentralized messaging covers the infrastructure for instant messaging, audio and video calls that does not depend on a single corporate backend. This category groups WebRTC media servers, federated XMPP and Matrix ecosystems, and privacy-first P2P solutions so administrators can assemble a sovereign real-time communications stack.

## WebRTC and Media Servers

- [Jitsi Meet](jitsi-meet.md) — video conferencing platform with media routing nodes.
- [Janus Gateway](janus-gateway.md) — universal WebRTC gateway for media stream integration.
- [Galene](galene.md) — ultra-light SFU server in Go for broadcasts and lectures.
- [Coturn](coturn.md) — TURN/STUN server for NAT traversal and video calls.

## XMPP Ecosystem

- [ejabberd](ejabberd.md) — scalable XMPP server written in Erlang.
- [Prosody IM](prosody.md) — lightweight and flexible XMPP server written in Lua.
- [Conversations](conversations.md) — reference Android client with voice and video.
- [Dino](dino.md) — modern native XMPP client for Linux (GTK).

## Matrix Ecosystem

- [Synapse](synapse.md) — reference Matrix homeserver implementation.
- [Dendrite](dendrite.md) — second-generation Matrix homeserver in Go.
- [Conduit](conduit.md) — lightweight single-binary Matrix homeserver.
- [Element](element.md) — official multiplatform Matrix client.
- [nheko](nheko.md) — fast native Matrix client in C++/Qt.

## P2P and Privacy-First

- [Jami](jami.md) — distributed serverless network built on a distributed hash table (DHT).
- [SimpleX Chat](simplesx-chat.md) — messenger without user IDs via ephemeral relays.
- [Signal](signal.md) — open-source messaging client with a centralized backend.

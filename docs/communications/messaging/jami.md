# Jami

Jami (GNU Jami) is a peer-to-peer communication platform that functions without any central server, using a distributed hash table (DHT) to establish direct connections between participants. It provides encrypted messaging, voice and video calls, and file sharing with strong operational control by users. Jami is a solid choice for a truly serverless, privacy-first communications system.

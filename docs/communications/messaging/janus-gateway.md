# Janus Gateway

Janus is a general-purpose, open-source WebRTC gateway that acts as a media server bridging browser-based and native WebRTC clients. Through a set of pluggable modules it supports video rooms, audio bridges, recording, streaming and SIP interop with fine-grained control over media flows. Janus is a flexible building block for embedding real-time media into custom applications.

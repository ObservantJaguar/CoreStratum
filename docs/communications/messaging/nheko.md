# nheko

nheko is a fast native Matrix client for desktop written in C++ with the Qt framework. It offers a modern, functional interface with support for end-to-end encryption, voice and video calls, and complete room management. As a lightweight native application, nheko is a good choice for users who prefer a desktop client without the overhead of a browser-based UI.

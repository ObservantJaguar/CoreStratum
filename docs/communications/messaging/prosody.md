# Prosody IM

Prosody is a lightweight, flexible XMPP server written in Lua with a strong focus on simplicity and extensibility. Its small resource footprint and modular architecture make it easy to configure and extend for personal, community or enterprise messaging. Prosody supports modern XMPP features including group chats, file uploads and end-to-end encryption.

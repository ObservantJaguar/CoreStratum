# Signal

Signal is a messaging application whose client code is fully open source and offers strong, audited end-to-end encryption. While the clients are decentralized in their security model, the service relies on a centralized backend operated by the Signal Foundation. Signal is widely regarded as a benchmark for private messaging, and this page focuses on understanding its architecture and security properties.

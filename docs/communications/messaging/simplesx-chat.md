# SimpleX Chat

SimpleX Chat is a messaging platform that uses ephemeral relay queues instead of persistent user identifiers, so there are no user IDs or phone numbers to leak. Messages are addressed through individually generated queue addresses, which strengthens privacy while still requiring lightweight servers for message relay. SimpleX Chat supports encrypted one-to-one and group messaging with end-to-end encryption and simplified self-hosting.

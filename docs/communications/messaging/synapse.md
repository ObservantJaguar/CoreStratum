# Synapse

Synapse is the reference homeserver implementation of the Matrix protocol, first developed alongside the protocol itself. It provides full support for the Matrix federation, end-to-end encrypted messaging, group chat, bridged services and the standard Matrix client-server API. Synapse is the most mature and feature-complete option for running a self-hosted Matrix server.

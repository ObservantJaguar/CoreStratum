# FreePBX

FreePBX is a graphical web interface used to configure and manage an Asterisk-based PBX. It abstracts the raw dialplan and configuration files behind an intuitive GUI, covering extensions, trunks, IVR, reporting and much more. FreePBX dramatically lowers the barrier to building a full-featured IP telephony system.

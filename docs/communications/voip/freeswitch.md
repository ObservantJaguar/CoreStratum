# FreeSWITCH

FreeSWITCH is an open-source communications platform for routing and switching voice and video calls. It provides a flexible, multi-protocol core with a powerful event system, making it suitable for PBXes, conference bridges, IVR and large-scale media applications. FreeSWITCH combines the reliability of a carrier-grade system with a broad embeddable API.

# Incredible PBX

Incredible PBX is a hardened telephony build that ships with a preinstalled firewall and a carefully configured Asterisk-based phone system. It focuses on security and out-of-the-box functionality, bundling features such as auto-attendants, voice mail and fail2ban from the start. Incredible PBX is a convenient foundation for a low-maintenance, protected PBX.

# IP Telephony

IP telephony (VoIP) replaces traditional telephone exchanges with software private branch exchanges (PBX) and SIP proxies running on standard hardware. This category covers open-source IP PBX systems, graphical management interfaces and high-performance SIP signaling servers used to build autonomous voice communications.

- [Asterisk](asterisk.md) — open-source PBX with flexible call logic.
- [FreePBX](freepbx.md) — graphical web interface for configuring and managing Asterisk.
- [Issabel](issabel.md) — IP-PBX distribution combining telephony, mail and fax.
- [VitalPBX](vitalpbx.md) — modern telephony platform based on Asterisk.
- [Incredible PBX](incredible-pbx.md) — hardened telephony build with a preinstalled firewall.
- [Kamailio](kamailio.md) — high-performance SIP proxy server for critical loads.
- [FreeSWITCH](freeswitch.md) — communications platform for voice and video.

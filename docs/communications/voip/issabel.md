# Issabel

Issabel is a turnkey IP-PBX distribution that combines telephony, email and fax services in a single, easily installable platform. Based on Asterisk, it provides a unified web portal for managing phone systems, contacts and messaging in one place. Issabel is aimed at self-hosted voice and unified communications deployments.

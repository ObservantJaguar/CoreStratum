# Kamailio

Kamailio is a high-performance open-source SIP proxy server designed to handle very large numbers of concurrent sessions. It excels at routing and load balancing SIP signaling feeds, acting as a registrar, proxy and edge gateway for carrier-grade voice networks. Kamailio is the choice when raw SIP performance and control are required.

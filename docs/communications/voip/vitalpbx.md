# VitalPBX

VitalPBX is a modern telephony platform built on top of Asterisk with a contemporary web interface. It includes high-availability clustering, extensive integrations and a well-structured API, making it suitable for growing organizations. VitalPBX packages enterprise-style contact-center and collaboration features into a manageable self-hosted system.

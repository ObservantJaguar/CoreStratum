# Apache HTTP Server

Apache HTTP Server is the classic extensible web server with a modular architecture that has powered a large part of the internet for decades. Its per-directory configuration files (`.htaccess`), broad module ecosystem and virtual hosting support let administrators shape behavior precisely. It remains a robust foundation for general-purpose web hosting.

# Caddy

Caddy is a modern web server that manages HTTPS automatically, provisioning and renewing TLS certificates through Let's Encrypt out of the box. Its simple declarative configuration, sane defaults and built-in reverse proxy and load balancing make secure deployment dramatically easier. Caddy is a strong choice when automatic secure-by-default hosting is the priority.

# HAProxy

HAProxy is a high-performance TCP/HTTP load balancer and proxy that is widely used to distribute traffic across backend servers. It provides advanced health checking, sticky sessions, traffic shaping and detailed statistics, while maintaining very low latency under heavy load. HAProxy is the de facto standard for fronting high-availability web applications.

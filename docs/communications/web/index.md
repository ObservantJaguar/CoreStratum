# Web Servers and Proxies

Web servers and reverse proxies handle content delivery, TLS termination and load balancing for the front-end of your services. This category covers high-performance servers, automatic HTTPS management and traffic distribution tools that protect the application backends they sit in front of.

- [Nginx](nginx.md) — efficient reverse proxy for SSL termination and backend protection.
- [Apache HTTP Server](apache-http-server.md) — classic extensible web server with a modular architecture.
- [Caddy](caddy.md) — modern web server with automatic HTTPS management.
- [HAProxy](haproxy.md) — high-performance TCP/HTTP load balancer.

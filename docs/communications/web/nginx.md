# Nginx

Nginx is a high-performance web server and reverse proxy known for its event-driven architecture and efficient handling of concurrent connections. It excels at terminating SSL/TLS and protecting application backends, while also serving as a load balancer, HTTP cache and mail proxy. Its flexible configuration and small resource footprint make it a standard choice for production deployments.

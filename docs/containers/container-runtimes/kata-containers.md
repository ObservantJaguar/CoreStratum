# Kata Containers

Kata Containers is a container runtime that combines the speed and manageability of containers with the security of virtual machines. Each Kata container runs inside its own lightweight VM, giving strong isolation through hardware virtualization while keeping the OCI and Kubernetes developer experience.

It is used in multi-tenant and security-sensitive environments where kernel-level isolation of traditional containers is insufficient.

# runc

runc is a CLI tool for spawning and running containers according to the Open Container Initiative (OCI) specification. It is the reference implementation of the OCI runtime spec and forms the default low-level runtime beneath Docker, containerd and many other engines.

runc creates and manages the namespaces, cgroups and security configuration required to isolate container processes on a Linux host.

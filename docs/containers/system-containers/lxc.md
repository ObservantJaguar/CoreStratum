# LXC

LXC (Linux Containers) is a system container technology that runs full Linux distributions in isolated environments sharing the host kernel. Each LXC container has its own root filesystem, init system, networking and processes, making it behave like a lightweight virtual machine.

LXC is widely used directly on the command line and serves as the foundation of LXD and platforms such as Proxmox VE.

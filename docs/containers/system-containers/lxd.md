# LXD

LXD is a system container and virtual machine manager built on top of LXC. It provides an image-based workflow with a REST API, command-line client and web interface for managing containers and VMs at scale on a single host or across a cluster.

LXD is popular for running full Linux systems in containers with a simple, cloud-like experience.

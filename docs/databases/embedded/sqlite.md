# SQLite

SQLite is a self-contained, serverless, zero-configuration embedded database library that reads and writes directly to a single disk file. It implements the full SQL standard and supports ACID transactions without requiring a separate database process or network connection.

Because it is file-based and reliable, SQLite is used in browsers, mobile operating systems, embedded devices and application-local storage. It offers a small footprint, cross-platform portability and low administration overhead.

# ArangoDB

ArangoDB is a multi-model database that combines document, graph, and key-value data models in a single engine with a unified query language, AQL. Its native graph traversals and an integrated low-latency document store make it a flexible choice for applications that want to mix connected data with conventional document workloads.

## Key features

- Multi-model: document, graph, and key-value in one engine
- Unified AQL query language across data models
- Native graph operations including traversals, shortest path, and pattern matching
- Flexible data modeling with JSON documents and schemaless schema evolution

## Notes for administrators

Deployment options include a single server, an actively replicated cluster, and a fully distributed cluster; choose based on consistency and availability requirements.

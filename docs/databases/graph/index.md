# Graph

Graph databases model data as nodes and relationships, optimized for traversing connected structures such as social networks, knowledge graphs, and recommendation engines. The engines in this category range from dedicated property-graph and multi-model databases to in-memory and PostgreSQL-extension approaches to connected data.

## Programs

- [Neo4j Community](neo4j.md) - the leading property graph database with Cypher
- [ArangoDB](arangodb.md) - multi-model database combining graph, document, and key-value
- [JanusGraph](janusgraph.md) - distributed graph database on cluster backends
- [Memgraph](memgraph.md) - in-memory graph database for real-time analytics
- [Apache AGE](apache-age.md) - graph extension providing openCypher on PostgreSQL

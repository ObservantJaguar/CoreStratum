# Neo4j Community

Neo4j is one of the most widely used graph databases, designed to represent and query data as a property graph of nodes and relationships. Its Cypher query language and indexed relationship traversal make it a strong choice for social networks, knowledge graphs, fraud detection, and recommendation systems, with the Community Edition providing an open-source version of the platform.

## Key features

- Property graph model with nodes, relationships, and properties
- Expressive Cypher query language
- Indexed adjacency for high-performance relationship traversal
- ACID transactions and full-text search support

## Notes for administrators

The Community Edition is open source; advanced features such as clustering and horizontal scale-out are reserved for the commercial Enterprise Edition.

# Redis

Redis is a high-performance, in-memory data structure store that supports strings, hashes, lists, sets, sorted sets, streams and more. It is often used as a cache, message broker and lightweight database, delivering sub-millisecond latency by keeping data in RAM.

Support for persistence, replication, clustering and built-in Lua scripting makes Redis suitable for caching layers, session storage, leaderboards, rate limiting and real-time feature queues in production systems.

# MariaDB

MariaDB is a community-developed fork of MySQL, created to preserve the open-source nature and backward compatibility of the original database. It is a drop-in replacement for MySQL with additional storage engines, performance optimizations and faster bug-fix cycles.

It powers many web applications, including LAMP stacks, and integrates with common frameworks and tools. Corporations and distributions rely on it as a stable, BSD/GPL dual-licensed relational database.

# MySQL

MySQL is the classic open-source relational database management system and the standard choice for web development. It provides robust transactional support, a mature SQL dialect and high performance tuned for read-heavy OLTP workloads.

Widely deployed as the database of record for content management systems, e-commerce platforms and backend services, MySQL offers replication, clustering, partitioning and a large ecosystem of tools and storage engines.

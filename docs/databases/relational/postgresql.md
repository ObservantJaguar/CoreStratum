# PostgreSQL

PostgreSQL is a powerful, open-source object-relational database system with a strong reputation for reliability, data integrity and standards compliance. It supports advanced data types, complex queries, foreign keys, triggers, views and transactional guarantees (ACID). Its extensible architecture allows custom data types, functions and procedural languages.

It is widely used as the primary database for web applications, data warehousing and geospatial workloads (via PostGIS). Capable of horizontal scaling through read replicas and partitioning, it remains a top choice for production data stores.

# Time-Series

Time-series databases are optimized for ingesting, storing and querying data that arrives continuously over time, such as application metrics, IoT sensor readings and financial tick data. They provide high write throughput, efficient compression and specialized query functions for time-based analysis.

- [ClickHouse](clickhouse.md)
- [InfluxDB](influxdb.md)

# InfluxDB

InfluxDB is a specialized time-series database built for metrics and monitoring workloads. It ingests large volumes of timestamped data efficiently, applies automatic retention policies and provides a purpose-built query language for time-based analytics.

It integrates closely with the open-source monitoring ecosystem, including Telegraf for collection and Chronograf for visualization, and is used for infrastructure monitoring, IoT telemetry and application performance tracking.

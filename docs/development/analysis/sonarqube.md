# SonarQube

SonarQube is a platform for continuous inspection of code quality and security. It performs static analysis across many languages, detecting bugs, code smells, vulnerabilities and coverage gaps, and reports them through an integrated web dashboard.

SonarQube is commonly deployed as a self-hosted quality gate in CI/CD pipelines.

# CMake

CMake is a cross-platform build automation and project configuration system that describes builds in declarative scripts and generates native build files for various toolchains and platforms. It handles dependencies, configuration options, installation and packaging in a consistent way.

CMake is a de-facto standard for C and C++ projects, abstracting platform differences so that a single source tree can build reliably across Linux, Windows and macOS with different compilers.

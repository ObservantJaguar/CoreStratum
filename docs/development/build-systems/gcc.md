# GCC

The GNU Compiler Collection (GCC) is a classic, mature suite of compilers supporting C, C++, Fortran, Ada and other languages. It is the default and reference compiler toolchain on GNU/Linux systems and is renowned for its broad target architecture support and heavily optimized code generation.

GCC is the foundation of most Linux distributions and embedded development ecosystems. It includes frontends for multiple languages, the accompanying libstdc++ runtime and the GNU binutils toolchain.

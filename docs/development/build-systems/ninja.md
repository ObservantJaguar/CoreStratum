# Ninja

Ninja is a compact, fast build system focused on speed of execution rather than full-featured ease of use. It is deliberately minimal, designed to be generated by higher-level tools such as CMake, and is engineered for maximal parallel build throughput.

Because of its low overhead and efficient incremental builds, Ninja is the default backend for many large C and C++ projects, including the Chrome and LLVM build systems, making it a cornerstone of modern high-performance compilation workflows.

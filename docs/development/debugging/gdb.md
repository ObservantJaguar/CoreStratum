# GDB

The GNU Debugger (GDB) is the standard command-line debugger on Linux and other Unix-like systems. It allows developers to control program execution, set breakpoints, inspect variables and memory, and analyze core dumps to diagnose crashes and subtle runtime bugs.

GDB supports multiple languages, including C, C++, Rust and Go, and integrates with IDE frontends. It is an indispensable tool for low-level debugging, tracing program flow and understanding complex failure modes in native code.

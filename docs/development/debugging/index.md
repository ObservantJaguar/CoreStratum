# Debugging and Profiling

Debugging and profiling tools give developers deep visibility into program behavior during execution. Debuggers allow step-by-step inspection of running code, while tracing and analysis tools reveal system calls, library calls and memory usage to locate bugs, bottlenecks and resource leaks.

- [GDB](gdb.md)
- [Strace](strace.md)
- [Ltrace](ltrace.md)
- [Valgrind](valgrind.md)

# Ltrace

Ltrace is a debugging utility that traces the runtime calls a process makes to functions in dynamic libraries, complementing strace which focuses on system calls. It records library calls along with their arguments and return values.

It helps diagnose issues such as failed dynamic library calls, unexpected function invocations and integration problems between a program and its shared dependencies.

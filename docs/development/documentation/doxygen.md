# Doxygen

Doxygen is a documentation generator that extracts comments and structure from source code to produce reference documentation in HTML, LaTeX, man pages or other formats. It supports C, C++, Python, Java, C# and many other languages.

Documentation written as structured comments is turned into cross-referenced, navigable API references with minimal effort.

# Documentation

Documentation tools support the writing, generation and maintenance of software documentation, including static site generators, API reference tools and literate programming utilities. They help teams produce consistent, maintainable and versioned technical documentation.

- [Doxygen](doxygen.md) — source-code documentation generator.
- [Sphinx](sphinx.md) — documentation generator with cross-references and indexing.
- [MkDocs](mkdocs.md) — simple static site generator from Markdown.

# MkDocs

MkDocs is a fast, simple static site generator oriented toward project documentation. It builds HTML documentation from Markdown sources with a single configuration file, and can be extended with plugins and themes.

Combined with the Material theme, it is a popular choice for clean, searchable technical documentation.

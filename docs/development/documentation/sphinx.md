# Sphinx

Sphinx is a documentation generator originally built for Python but usable for any language. It converts reStructuredText or Markdown sources into HTML, PDF, EPUB and other outputs, with automatic cross-references, indexing and theming.

It is the engine behind many popular project documentation sites, including Read the Docs.

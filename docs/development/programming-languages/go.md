# Go

Go (Golang) is a compiled programming language designed at Google for building scalable and reliable network services. It combines static typing, a fast compiler, garbage collection and simple concurrency primitives (goroutines and channels).

A large part of the modern cloud-native ecosystem — Docker, Kubernetes, Terraform, Prometheus and many others — is written in Go.

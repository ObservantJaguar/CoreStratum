# JavaScript

JavaScript is the language of the web: it runs in every browser and, through Node.js, on servers and tooling. Together with TypeScript (its typed superset) it powers frontend frameworks (React, Vue, Svelte), backend runtimes and build tools.

For fullstack and frontend developers, JavaScript/TypeScript is effectively mandatory; backend developers encounter it in Node.js services and build scripts.

# Rust

Rust is a modern systems programming language focused on safety and performance. Its ownership model guarantees memory safety without a garbage collector, preventing data races and many classes of memory bugs at compile time.

Rust is increasingly used for infrastructure tooling: many new generation tools (for example parts of the container and observability ecosystem) are written in it.

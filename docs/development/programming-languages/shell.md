# Shell

The shell is both a command interpreter and a scripting language to control the operating system. Writing robust shell scripts — with Bash and Zsh being the most common on Linux — is a core skill for system administration and DevOps.

Shell scripting is used to automate routine tasks, glue together tools and build the entry points of larger infrastructure pipelines.

# Ghidra

Ghidra is a software reverse-engineering suite developed by the NSA. It includes a disassembler, decompiler, graphing and scripting capabilities in a graphical interface, supporting many processor architectures and executable formats.

Its built-in decompiler and extensible API make it widely used in malware analysis and vulnerability research.

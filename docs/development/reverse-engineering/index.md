# Reverse Engineering

Reverse engineering encompasses tools and techniques for analyzing compiled binaries to understand their structure, behavior and intentions when source code is unavailable. This includes disassembly, decompilation, binary analysis and protocol inspection.

- [radare2](radare2.md) — complete reverse-engineering framework.
- [Ghidra](ghidra.md) — software reverse-engineering suite with decompiler.

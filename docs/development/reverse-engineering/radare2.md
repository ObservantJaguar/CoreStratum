# radare2

radare2 is a complete framework for reverse engineering and binary analysis. It provides disassembly, debugging, binary file analysis and scripting capabilities from a single command-line tool, supporting a very wide range of architectures and file formats.

It is a popular open-source alternative to commercial reverse-engineering suites, with a rich plugin ecosystem.

# Cypress

Cypress is a modern end-to-end testing framework for web applications. It runs tests directly in the browser, providing fast, reliable and debuggable E2E tests with an interactive test runner and time-travel debugging.

Cypress focuses on developer experience and is a popular choice for front-end teams.

# Testing

Testing tools help verify that software behaves correctly through unit, integration, end-to-end and performance test suites. Frameworks and harnesses automate the execution, assertion and reporting of tests to catch regressions early in the development cycle.

- [Selenium](selenium.md) — browser automation for end-to-end web testing.
- [Cypress](cypress.md) — modern end-to-end testing for web applications.
- [Playwright](playwright.md) — cross-browser automation by Microsoft.

# Playwright

Playwright is a browser automation library by Microsoft for end-to-end testing of web applications. It supports Chromium, Firefox and WebKit with a single API, and offers features such as network interception, mobile emulation and parallel test execution.

It is widely used for reliable cross-browser testing and web scraping.

# Forgejo

Forgejo is an independent, community-driven fork of Gitea focused on complete software freedom and decentralized project governance. It offers the same self-hosted Git hosting capabilities: repositories, issues, pull requests, actions and package management.

Forgejo is backed by a non-profit and prioritizes open governance and user control over the platform.

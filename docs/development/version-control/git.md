# Git

Git is a distributed version control system designed to handle everything from small to very large projects with speed and efficiency. Every working copy contains the full history, which enables offline work and flexible branching and merging.

Git is the foundation of modern software development: platforms such as GitHub, GitLab and Gitea wrap it with collaboration, code review and CI/CD features.

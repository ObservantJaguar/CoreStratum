# Gitea

Gitea is a lightweight, self-hosted Git service written in Go. It provides repository hosting with an issue tracker, pull requests, project boards, a built-in CI/CD (Actions) and an integrated package registry.

Its low resource footprint makes it an ideal choice for small teams and self-hosted infrastructure that want a GitHub-like experience without the overhead.

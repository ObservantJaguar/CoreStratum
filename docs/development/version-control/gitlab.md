# GitLab Community Edition

GitLab is a complete DevOps platform covering the whole software lifecycle. The Community Edition (CE) is the open-source edition that provides repository hosting, merge requests, an integrated CI/CD pipeline engine, container registry, issue tracking and much more.

It is a common choice for organizations that want a single self-hosted platform for source control and automated delivery.

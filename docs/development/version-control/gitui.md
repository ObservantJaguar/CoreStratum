# GitUI

GitUI is a blazing-fast, portable terminal client for Git written in Rust. It provides a keyboard-driven interface for common Git operations such as staging, committing, branching and viewing diffs and logs.

Its single-binary distribution and low resource usage make it a convenient tool for remote and containerized environments.

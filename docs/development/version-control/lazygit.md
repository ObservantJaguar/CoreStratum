# LazyGit

LazyGit is a terminal user interface for Git. It provides a fast, visual way to manage branches, commits, stashes and remotes directly from the command line without memorizing complex Git commands.

It is popular among developers and administrators who work heavily in the terminal and want an interactive alternative to command-line Git.

# Emacs

Emacs is a family of text editors known for their extensibility, with GNU Emacs being the most widely used implementation. It provides a Lisp-based extension language (Emacs Lisp) that allows deep customization of the editing experience.

Beyond editing, Emacs functions as an integrated environment for email, org-mode planning, terminals, and many other workflows.

# Neovim

Neovim is a modern, extensible rewrite of Vim. It keeps the modal editing model and keybindings of classic Vim while adding an embedded Lua runtime for configuration and plugins, asynchronous plugin execution, a built-in terminal and a remote plugin architecture.

It is a popular choice for administrators and developers who want a fast, keyboard-driven editor that is fully scriptable.

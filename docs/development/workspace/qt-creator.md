# Qt Creator

Qt Creator is an integrated development environment optimized for building cross-platform applications with the Qt framework. It includes a code editor, visual debugger, integrated UI designer, and tools for profiling and analyzing applications.

It is especially relevant for teams developing desktop, embedded and mobile applications in C++ and QML.

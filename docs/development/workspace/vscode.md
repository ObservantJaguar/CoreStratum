# Visual Studio Code (OSS)

Visual Studio Code is a source-code editor developed by Microsoft. The open-source distribution, known as Code - OSS, is the community build without proprietary telemetry and branding; the official "Visual Studio Code" binary adds Microsoft-specific services.

It is widely used for development and infrastructure work thanks to its extension ecosystem, integrated terminal, debugger and language support.

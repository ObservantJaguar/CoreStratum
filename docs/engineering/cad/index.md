# CAD — Engineering Design

CAD (Computer-Aided Design) covers open-source tools for creating, editing, and documenting mechanical and architectural designs. The category includes parametric and direct modeling systems for 3D design, 2D drafting tools, and scriptable modeling environments.

- [FreeCAD](freecad.md) — parametric 3D CAD modeler
- [LibreCAD](librecad.md) — open-source 2D CAD application
- [QCAD](qcad.md) — 2D CAD system
- [BRL-CAD](brl-cad.md) — constructive solid geometry modeling system
- [OpenSCAD](openscad.md) — script-based 3D modeler
- [Salome](salome.md) — platform for pre- and post-processing of numerical simulations, including the Salome-Meca distribution for Code_Aster

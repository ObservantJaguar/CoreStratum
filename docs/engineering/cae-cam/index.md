# CAE/CAM — Engineering Analysis and Manufacturing

CAE/CAM covers open-source tools for engineering simulation and computer-aided manufacturing. The category includes computational fluid dynamics solvers, finite-element analysis software, and toolpath generation for CNC machining.

## CAE — Engineering Analysis

- [OpenFOAM](openfoam.md) — open-source computational fluid dynamics toolbox
- [Code_Aster](code-aster.md) — open-source finite-element structural analysis software
- [CalculiX](calculix.md) — finite-element analysis package

## CAM — Computer-Aided Manufacturing

- [PyCAM](pycam.md) — open-source CAM toolpath generator

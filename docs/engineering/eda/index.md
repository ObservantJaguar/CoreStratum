# EDA — Electronics Design

EDA (Electronic Design Automation) covers open-source tools for the design of printed circuit boards, schematics, and electronic circuits. The category includes full electronics design suites, schematic capture and layout tools, and breadboarding visualization utilities.

- [KiCad](kicad.md) — full open-source EDA suite for schematic and PCB design
- [gEDA](geda.md) — suite of open-source electronics design tools
- [Fritzing](fritzing.md) — electronics design tool for prototyping and documentation
- [Pcb-rnd](pcb-rnd.md) — modular PCB layout editor

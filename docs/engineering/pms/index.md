# PMS — Project Management and Bug Tracking

PMS covers open-source platforms for planning projects, tracking tasks, and managing software defects. The category includes full project management suites, agile and kanban boards, and dedicated bug-tracking systems that integrate with development workflows.

## Project and Task Management

- [OpenProject](openproject.md) — open-source project management platform
- [Taiga](taiga.md) — agile project management platform
- [Focalboard](focalboard.md) — open-source project management and team collaboration tool

## Bug Tracking

- [MantisBT](mantisbt.md) — open-source web-based bug tracker
- [Redmine](redmine.md) — flexible project and issue tracking web application
- [Gitea Issues](gitea-issues.md) — issue tracking built into the Gitea git platform

# SAM — Asset and Resource Monitoring

SAM (Software and Asset Management) covers open-source tools for tracking organizational assets and monitoring resource usage. The category includes asset accounting systems and time-tracking platforms for logging how staff hours are spent.

- [eHour](ehour.md) — open-source time-tracking tool
- [Kimai](kimai.md) — time-tracking application

# Distributed Filesystems

Distributed filesystems present a single coherent namespace backed by storage distributed across multiple nodes. This category documents cluster filesystems used for high availability, shared storage, and large-scale data access across clusters.

- [CephFS](../../storage/distributed/ceph.md) — the distributed file interface of the Ceph platform.
- [MooseFS](moosefs.md) — fault-tolerant distributed network filesystem.
- [Lustre](lustre.md) — high-performance parallel filesystem for HPC.
- [BeeGFS](beegfs.md) — parallel cluster filesystem for demanding storage workloads.

# Network Filesystems

Network filesystems enable accessing and sharing data across a network as if it were local storage. This category documents the standard access protocols used for file sharing between hosts and storage servers, along with entries for network filesystems documented elsewhere.

- [NFS](nfs.md) — the standard network filesystem for Unix and Linux.
- [SMB/CIFS (Samba)](samba.md) — Windows-compatible file sharing via Samba.
- [GlusterFS](../../storage/distributed/glusterfs.md) — scalable network filesystem (covered under Distributed Storage).
- [CephFS](../../storage/distributed/ceph.md) — the POSIX file interface of the Ceph platform.
- [SSHFS](sshfs.md) — mount remote filesystems securely over SSH/SFTP.

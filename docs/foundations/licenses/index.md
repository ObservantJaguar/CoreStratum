# Licensing

A software license defines the legal terms under which source code may be used, modified and redistributed. Choosing the right license determines how much control you keep over your code and how freely others can build on it. For an open infrastructure you want licenses that guarantee visibility and, depending on your goals, keep derived work open.

## License types

- **Permissive (BSD, MIT, Apache 2.0)** — maximum freedom to integrate and reuse code without a requirement to release derived work under the same terms. Best when you want wide adoption.
- **Strong Copyleft (GPL v2/v3, AGPL)** — requires that all derived works remain open source under the same license. Best when you want to guarantee that improvements are shared back.
- **Weak Copyleft (LGPL, MPL)** — allows linking against closed-source code while keeping the copylefted library itself open. Best for shared libraries that may be used by proprietary software.

# CoreStratum

**CoreStratum** is an open-source encyclopedia of open technologies — a curated reference for **system administrators**, **DevOps engineers** and other IT professionals. Every tool has its own page with an overview, links to official documentation and setup guides.

## How to use

Browse the sidebar or the table of contents below. Pick the domain that matches your task, open the category, then read the page for a specific tool.

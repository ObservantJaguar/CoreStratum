# Message Brokers

Message brokers provide asynchronous communication between services: producers publish messages, consumers subscribe to them, and the broker handles routing, queues and delivery guarantees. They are the backbone of decoupled and event-driven architectures.

- [RabbitMQ](rabbitmq.md) — universal multi-protocol message broker (AMQP).
- [Apache Kafka](kafka.md) — distributed streaming platform for high-throughput data pipelines.

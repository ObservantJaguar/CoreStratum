# Apache Kafka

Apache Kafka is a distributed event streaming platform designed for high-throughput, fault-tolerant data pipelines. It stores messages in a partitioned, ordered commit log, with producers, consumers, consumer groups and exactly-once semantics.

Kafka is the standard backbone for event-driven architectures, log aggregation, stream processing (Kafka Streams, ksqlDB) and CDC pipelines.

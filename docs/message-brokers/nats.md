# NATS

NATS is a lightweight, high-performance open-source messaging system built for cloud-native applications. It offers three models in one server: core NATS (at-most-once publish/subscribe), JetStream (durable, at-least-once message streaming with consumers), and request/reply.

Its minimal footprint and simple protocol make it a popular choice for microservices, IoT and Kubernetes-native workloads where Kafka or RabbitMQ feel heavy.

# RabbitMQ

RabbitMQ is a widely deployed open-source message broker implementing AMQP 0-9-1 and supporting MQTT, STOMP and WebSocket. It provides flexible routing (direct, topic, headers, fanout exchanges), reliable queues, clustering and high availability.

It is a classic choice for decoupling services, task queues, and RPC-style request/reply patterns with a friendly management UI.

# ISC DHCP

ISC DHCP is the long-standing open-source reference implementation of the DHCP protocol, providing DHCPv4 and DHCPv6 servers as well as relay agents. It remains the classic choice for enterprise networks that need predictable static reservations, failover pairs, and dynamic DNS updates.

Official site: <https://www.isc.org/dhcp/>

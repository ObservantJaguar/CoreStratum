# Kea

Kea is the modern DHCP suite from ISC, offering high-performance DHCPv4 and DHCPv6 servers with a modular, extensible architecture. Its REST API, database backends (MySQL, PostgreSQL), and hosting-as-a-service design make it more scalable and operationally automatable than the legacy ISC DHCP server.

Official site: <https://www.isc.org/kea/>

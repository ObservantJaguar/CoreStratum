# Diagnostics

Network diagnostics covers the tools used to inspect, capture, and analyze network traffic and to trace routing paths between hosts. These utilities are essential for troubleshooting connectivity, performance degradation, and protocol-level problems in both LAN and WAN environments.

- [Wireshark](wireshark.md) — graphical protocol analyzer for deep packet inspection.
- [Tcpdump](tcpdump.md) — command-line packet capture and analysis utility.
- [MTR](mtr.md) — network diagnostic tool combining ping and traceroute.
- [Netcat](netcat.md) — versatile TCP/UDP network utility.

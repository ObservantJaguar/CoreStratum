# Netcat (nc)

Netcat is a versatile network utility described as the "Swiss-army knife" of TCP/UDP operations. It can open TCP connections, send raw data, listen on ports, and act as a simple client or server, making it a standard tool for port probing, debugging services, and scripting network tests.

Official documentation: <https://nc110.sourceforge.io>

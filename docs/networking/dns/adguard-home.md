# AdGuard Home

AdGuard Home is a network-wide DNS sinkhole for blocking ads and trackers across all devices on a home or small office network. It acts as a DNS server with parental controls, filtering rules and privacy protection, configurable through a clean web interface.

Official site: <https://adguard.com/en/adguard-home/overview.html>

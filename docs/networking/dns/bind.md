# BIND 9

BIND 9 (Berkeley Internet Name Domain) is the reference implementation of the DNS protocol, offering a full-featured authoritative name server and recursive resolver. It supports DNSSEC, dynamic updates, zones transfer (AXFR/IXFR), and advanced configuration for split-horizon and conditional forwarding setups.

Official site: <https://www.isc.org/bind/>

# dnsmasq

dnsmasq is a lightweight DNS forwarder and DHCP server designed for small networks, embedded devices and virtualized hosts. It provides local caching, wildcard DNS for development, and simple host aliases built on top of /etc/hosts, making it a convenient solution for LANs and test environments.

Official site: <https://thekelleys.org.uk/dnsmasq/doc.html>

# DNS

The Domain Name System (DNS) resolves human-readable hostnames into IP addresses. This category covers authoritative servers, resolvers, zone management, DNSSEC, and related infrastructure such as conditional forwarding and split-horizon DNS.

- [BIND 9](bind.md) — the reference DNS implementation for authoritative and recursive service.
- [PowerDNS](powerdns.md) — modular DNS suite backed by SQL, LDAP and API stores.
- [Unbound](unbound.md) — validating, recursive, caching resolver from NLnet Labs.
- [Knot DNS](knot.md) — high-performance authoritative name server.
- [CoreDNS](coredns.md) — plugin-based DNS server, default in Kubernetes service discovery.
- [dnsmasq](dnsmasq.md) — lightweight DNS forwarder for small networks and embedded hosts.
- [AdGuard Home](adguard-home.md) — network-wide ad and tracker-blocking DNS.

# PowerDNS

PowerDNS is a modular DNS server suite split into the PowerDNS Authoritative Server, the PowerDNS Recursor, and PowerDNS-Admin for management. It stands out for its wide range of backends (including SQL databases, LDAP, and API stores) that allow zones to live outside flat zone files.

Official site: <https://www.powerdns.com>

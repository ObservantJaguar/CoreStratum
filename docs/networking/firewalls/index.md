# Firewalls

Firewalls enforce network security policies by filtering traffic based on rulesets. This category covers packet-filtering frameworks and network address translation (NAT) tools used on Linux and BSD systems to control inbound and outbound traffic and protect hosts and networks.

- [NFTables](nftables.md) — modern Linux packet filtering framework.
- [IPTables](iptables.md) — classic Linux packet filtering interface.
- [PF](pf.md) — reference packet filter firewall on FreeBSD and OpenBSD.

# PF (Packet Filter)

PF is the reference packet filter firewall shipped with OpenBSD and FreeBSD. It provides a flexible ruleset language for packet filtering, NAT, and traffic shaping, and is considered a benchmark for stateful firewall implementation in BSD systems.

Official handbook: <https://docs.freebsd.org/en/books/handbook/firewalls/#firewalls-pf>

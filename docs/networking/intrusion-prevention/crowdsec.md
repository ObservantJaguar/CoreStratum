# CrowdSec

CrowdSec is an open-source behavioral intrusion prevention system (IPS) that analyzes logs to detect threat patterns and shares remediation signals through a collaborative community blocklist. It integrates with firewalls and reverse proxies to block offending IPs automatically.

Official documentation: <https://docs.crowdsec.net>

# FreeRADIUS

FreeRADIUS is a high-performance server implementing the RADIUS protocol for centralized authentication, authorization, and accounting (AAA). It is widely used for network access control, VPN authentication, and 802.1X/EAP deployments, supporting a large set of modules and backends.

Official site: <https://freeradius.org>

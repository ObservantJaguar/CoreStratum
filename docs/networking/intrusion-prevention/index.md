# Intrusion Prevention

Intrusion prevention covers systems that detect and automatically respond to malicious activity on a network. These tools monitor logs and traffic, block offending IP addresses, and enforce network access control policies to reduce the impact of attacks.

- [Fail2ban](fail2ban.md) — automatic IP blocking based on attack signatures.
- [CrowdSec](crowdsec.md) — behavioral threat analysis and IPS based on logs.
- [PacketFence](packetfence.md) — full-featured network access control (NAC) solution.
- [FreeRADIUS](freeradius.md) — server for centralized authentication and accounting.

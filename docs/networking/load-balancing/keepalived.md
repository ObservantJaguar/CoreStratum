# Keepalived

Keepalived provides high-availability and load-balancing capabilities on Linux through the VRRP protocol and the Linux Virtual Server (LVS) kernel frameworks. It enables failover of virtual IPs between nodes and layer-4-based load balancing for a cluster of real servers.

Official site: <https://www.keepalived.org>

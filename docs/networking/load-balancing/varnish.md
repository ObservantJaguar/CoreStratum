# Varnish

Varnish is a high-performance HTTP accelerator commonly used to cache and serve content in front of web backends. It excels as a reverse proxy and cache that offloads requests from application servers, with an expressive VCL configuration language for request handling and caching rules.

Official site: <https://varnish-cache.org>

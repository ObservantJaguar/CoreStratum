# FRRouting

FRRouting (FRR) is a free and open-source Internet routing protocol suite that runs on standard Linux and BSD. It provides OSPFv2/v3, BGP, IS-IS, RIP and PIM daemons integrated into the kernel's FIB, making it a practical replacement for proprietary router software in data-center and edge deployments.

Official site: <https://frrouting.org>

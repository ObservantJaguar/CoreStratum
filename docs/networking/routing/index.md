# Routing

Routing covers the protocols and software responsible for directing network traffic between hosts and subnets. This category documents dynamic routing protocols such as OSPF and BGP, routing daemons, and policy-based routing configurations.

- [FRRouting](frr.md) — open-source routing suite with OSPF, BGP, IS-IS and PIM.
- [Bird](bird.md) — lightweight BGP/OSPF routing daemon for ISPs and exchanges.
- [VyOS](vyos.md) — open-source network operating system for routers and firewalls.
- [Open vSwitch](openvswitch.md) — virtual switch supporting programmatic routed and tunneled forwarding.

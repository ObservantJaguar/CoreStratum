# Open vSwitch

Open vSwitch (OVS) is a production-quality multilayer virtual switch that enables programmatic network configuration in virtualized and containerized environments. It supports both L2 switching and routed forwarding planes (including tunnel-based routing with VXLAN, GRE, and Geneve), is OpenFlow-compatible, and provides features like QoS, bonding, and flow-based forwarding.

Official site: <https://www.openvswitch.org>

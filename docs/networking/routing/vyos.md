# VyOS

VyOS is an open-source network operating system that ships as a router, firewall and VPN platform. It offers a configuration-file-based CLI, static and dynamic routing (OSPF, BGP, IS-IS), and is a popular drop-in replacement for commercial routers in lab and production networks.

Official site: <https://vyos.io>

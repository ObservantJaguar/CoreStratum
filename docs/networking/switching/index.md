# Switching

Switching covers the technology and configuration of network switches, including L2 forwarding, VLANs, spanning tree, link aggregation, and management of managed switching platforms. This category focuses on software-defined switching and OpenFlow controllers.

- [Open vSwitch](../routing/openvswitch.md) — production-grade virtual switch for L2 and tunnel-based switching.
- [Lagopus](lagopus.md) — high-performance SDN switch using OpenFlow and P4.
- [ONOS](onos.md) — open-source SDN controller for service providers and data centers.
- [FAUCET](faucet.md) — config-driven OpenFlow controller for software-defined switching.

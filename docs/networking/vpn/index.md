# VPN

Virtual private networks (VPNs) create encrypted tunnels over untrusted networks to securely connect hosts and sites. This category covers both traditional and modern VPN solutions, including peer-to-peer mesh platforms for simplified site-to-site and remote access connectivity.

- [WireGuard](wireguard.md) — modern high-speed VPN protocol with cryptography.
- [OpenVPN](openvpn.md) — classic solution for encrypted channels.
- [Tailscale](tailscale.md) — mesh network (SDN) solution built on WireGuard.
- [ZeroTier](zerotier.md) — platform for virtualizing global networks (P2P SDN).

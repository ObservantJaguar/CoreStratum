# WireGuard

WireGuard is a modern, high-speed VPN protocol designed for simplicity and performance. It uses state-of-the-art cryptography, runs in the Linux kernel, and provides a minimal configuration surface, making it a preferred choice for secure site-to-site and remote access tunnels.

Official site: <https://www.wireguard.com>

# Grafana

Grafana is a widely adopted open-source analytics and visualization platform for metrics, logs, and traces. It connects to a broad range of data sources including Prometheus, Loki, Elasticsearch, and relational databases, and provides interactive dashboards, alerting, and annotation features. Its unified view of observability signals makes it a central component of modern monitoring stacks.

Official documentation: <https://grafana.com>

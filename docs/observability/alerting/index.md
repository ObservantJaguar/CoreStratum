# Visualization and Alerting

Visualization and alerting covers tools for the graphical representation of monitoring data and the delivery of notifications. The category includes the Grafana visualization platform for metrics, logs, and traces, the Kibana interface for Elasticsearch data, the Alertmanager component for grouping and routing Prometheus alerts, and Jaeger for distributed request tracing.

- [Grafana](grafana.md) — platform for visualizing metrics, logs, and traces.
- [Kibana](kibana.md) — visual interface for analyzing and navigating Elasticsearch data.
- [Alertmanager](alertmanager.md) — component for grouping and routing alert notifications.
- [Jaeger](jaeger.md) — system for distributed request tracing and monitoring.

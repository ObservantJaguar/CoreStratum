# Jaeger

Jaeger is an open-source distributed tracing system originally developed at Uber for monitoring and troubleshooting microservices-based architectures. It provides end-to-end request tracing, latency analysis, dependency graphs, and root-cause analysis across distributed transactions, integrating with observability backends for comprehensive monitoring.

Official documentation: <https://www.jaegertracing.io>

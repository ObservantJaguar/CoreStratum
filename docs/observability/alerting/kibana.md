# Kibana

Kibana is the data visualization and exploration layer of the Elastic Stack, providing a web interface for searching, analyzing, and visualizing data stored in Elasticsearch. It supports dashboards, charts, maps, log analytics, and machine learning features, serving as the primary user-facing view for Elasticsearch-based observability.

Official documentation: <https://www.elastic.co>

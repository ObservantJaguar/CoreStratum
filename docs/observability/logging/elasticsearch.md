# Elasticsearch

Elasticsearch is a distributed, RESTful search and analytics engine built on Apache Lucene, and the core storage and indexing component of the ELK stack. It stores documents as JSON, provides near-real-time full-text search, aggregations, and scalability across clusters, and serves as the foundation for indexing and querying centralized logs and application data.

Official documentation: <https://www.elastic.co>

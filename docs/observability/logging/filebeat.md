# Filebeat

Filebeat is a lightweight, resource-efficient agent in the Elastic stack that ships log files from hosts to Elasticsearch or Logstash. It tails files, handles rotation and multiline events, and provides a reliable delivery channel, making it the standard collector for forwarding textual logs into the ELK pipeline.

Official documentation: <https://www.elastic.co>

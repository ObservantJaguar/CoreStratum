# Fluent Bit

Fluent Bit is an ultra-lightweight, high-performance log processor and forwarder written in C. Optimized for containers and edge devices, it collects, filters, and ships logs and metrics to a wide range of outputs while consuming minimal CPU and memory, making it a common default sidecar logging collector in Kubernetes.

Official documentation: <https://docs.fluentbit.io>

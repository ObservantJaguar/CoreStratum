# Fluentd

Fluentd is a universal open-source data collector that unifies logging across sources and destinations. Written in Ruby with a flexible plug-in architecture, it captures, transforms, buffers, and routes log data, and has become a de-facto standard for log aggregation in cloud-native and containerized environments.

Official documentation: <https://docs.fluentd.org>

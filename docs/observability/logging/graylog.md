# Graylog

Graylog is a powerful open-source platform for centralized log collection, analysis and alerting in real time. It receives logs over syslog, GELF and other inputs, indexes them for fast search, and lets operators build dashboards and trigger alerts on patterns.

It is a heavyweight but capable alternative to ELK/Loki for organizations that want an all-in-one log management appliance.

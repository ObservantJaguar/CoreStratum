# Logstash

Logstash is a server-side data processing pipeline in the ELK stack that ingests data from many sources, transforms and enriches events, and ships them to destinations such as Elasticsearch. Its plugin-based architecture supports flexible parsing, filtering, and normalization of log and metric data before indexing.

Official documentation: <https://www.elastic.co>

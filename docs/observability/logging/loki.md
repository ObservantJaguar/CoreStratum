# Grafana Loki

Grafana Loki is a horizontally scalable log aggregation system from Grafana Labs that indexes only the metadata of log streams rather than the log content itself, dramatically reducing storage requirements. It is horizontally scalable, designed for cost efficiency, and integrates tightly with Grafana for visualization and querying alongside metrics and traces.

Official documentation: <https://grafana.com>

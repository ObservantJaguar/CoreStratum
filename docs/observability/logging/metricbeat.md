# Metricbeat

Metricbeat is a lightweight agent from the Elastic stack that collects system and service metrics and ships them to Elasticsearch or Logstash. It gathers operating system, container, and application metrics through modular collectors, complementing log-centric shippers with operational telemetry in the same Elastic pipeline.

Official documentation: <https://www.elastic.co>

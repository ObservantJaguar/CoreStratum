# Promtail

Promtail is the agent component of the Grafana Loki stack that discovers targets, tails log files, and forwards them to Loki. It supports file discovery, static and service discovery-based targets, and attaches labels to log streams so that Loki can index and query them efficiently.

Official documentation: <https://grafana.com/docs/loki/latest/send-data/promtail/>

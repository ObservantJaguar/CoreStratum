# Monitoring and Metrics

Monitoring and metrics systems collect, store, and analyze quantitative indicators of infrastructure and application health. The category covers the Prometheus pull-based stack and compatible time-series databases, enterprise-scale monitoring platforms, real-time performance agents, and lightweight exporters that feed hardware and process-level metrics into collectors.

- [Prometheus](prometheus.md) — the industry-standard pull-based monitoring and metrics system.
- [VictoriaMetrics](victoriametrics.md) — high-performance time-series database for long-term metric storage.
- [Zabbix](zabbix.md) — universal enterprise-class monitoring platform.
- [Netdata](netdata.md) — real-time system performance monitoring.
- [Node Exporter](node-exporter.md) — agent that exports operating system hardware metrics.
- [Process Exporter](process-exporter.md) — agent for detailed statistics on process groups.

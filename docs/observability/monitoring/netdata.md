# Netdata

Netdata is an open-source real-time monitoring agent that collects and visualizes thousands of system, container, and application metrics with sub-second granularity. Its zero-configuration dashboard renders live charts directly in the browser while keeping a tiny resource footprint on monitored hosts, making it well suited for granular performance observability.

Official documentation: <https://learn.netdata.cloud>

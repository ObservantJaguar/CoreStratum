# Node Exporter

Node Exporter is the official Prometheus agent that exports hardware and operating system metrics from a host, including CPU, memory, disk, filesystem, network, and process statistics. It exposes them over an HTTP endpoint in the Prometheus text format, enabling Prometheus and compatible collectors to scrape a full picture of each node automatically.

Official documentation: <https://github.com/prometheus/node_exporter>

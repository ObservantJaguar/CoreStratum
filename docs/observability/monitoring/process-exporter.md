# Process Exporter

Process Exporter is a Prometheus-compatible exporter that collects detailed metrics about running processes, aggregated by process group. It uses a pattern-based configuration to match processes into named groups and reports CPU, memory, descriptors, and state information for each group, giving operators visibility into application processes that plain node metrics cannot provide.

Official documentation: <https://github.com/ncabatoff/process-exporter>

# Prometheus

Prometheus is the industry-standard open-source monitoring system built around a pull-based collection model. It scrapes metrics from instrumented targets over HTTP, stores them as labeled time series in a built-in database, powers queries with the PromQL language, and integrates with Alertmanager for alerting. Its dimensional data model and active ecosystem of exporters have made it the de-facto default for cloud-native monitoring.

Official documentation: <https://prometheus.io>

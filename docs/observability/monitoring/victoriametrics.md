# VictoriaMetrics

VictoriaMetrics is a high-performance open-source time-series database designed for long-term storage and querying of metrics at scale. It is fully compatible with the Prometheus remote write and query APIs, offers aggressive compression and efficient resource usage, and provides clustering, downsampling, and retention control out of the box, making it a popular drop-in alternative for large Prometheus deployments.

Official documentation: <https://docs.victoriametrics.com>

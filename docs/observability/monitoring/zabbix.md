# Zabbix

Zabbix is a mature, enterprise-class open-source monitoring platform that collects metrics from servers, network devices, virtual machines, and applications. It provides agent-based and agentless monitoring, auto-discovery, flexible thresholds, and built-in alerting and visualization. Its centralized web interface and extensive scaling options make it a long-standing choice for corporate infrastructure environments.

Official documentation: <https://www.zabbix.com>

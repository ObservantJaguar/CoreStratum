# FreeBSD

FreeBSD is an advanced open-source operating system descended from the Berkeley Software Distribution of UNIX. It is renowned for high performance networking, a storage stack built around ZFS, and native isolation technologies such as jails and the bhyve hypervisor.

For administrators running storage, network or virtualisation workloads, FreeBSD offers a cohesive and well-documented system with a single integrated base. Its permissive licence also makes it a trusted base for many commercial appliances.

## Notes for administrators

- Provides ZFS, jails for OS-level isolation and bhyve for hardware virtualisation.
- The FreeBSD Handbook is widely regarded as one of the best structured operating-system references.
- Includes the PF and IPFW firewalls for packet filtering.

# illumos

illumos is a free and open-source operating system forked from OpenSolaris after Oracle discontinued its open development. It preserves the engineered quality of the Solaris base while remaining fully open, and serves as the foundation for several distributions such as SmartOS, OmniOS and OpenIndiana.

For administrators it offers capabilities rarely found together elsewhere: ZFS for data integrity, zones for lightweight OS-level virtualisation, DTrace for deep performance investigation and SMF for service management.

## Notes for administrators

- Uses ZFS as the default filesystem and volume manager.
- Zones provide efficient, isolated execution environments on a single kernel.
- DTrace enables safe, low-overhead runtime tracing of the whole system.

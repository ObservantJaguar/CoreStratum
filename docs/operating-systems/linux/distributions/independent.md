# Independent Distributions

Independent Linux distributions are not derived from Debian or Red Hat. They often explore different init systems, package managers, toolchains and design philosophies, and are frequently used in containers, security-sensitive environments and experimental infrastructure.

Notable independent systems:

- **Alpine Linux** — musl-based, security-focused minimalist distribution, widely used in containers.
- **Void Linux** — runit init system, XBPS package manager.
- **NixOS** — declarative configuration, reproducible builds.
- **Solus** — curated desktop distribution.
- **Chimera Linux** — LLVM toolchain, BSD-style userland.
- **Qubes OS** — security-focused, isolation-based desktop OS.
- **Whonix** — privacy and anonymity distribution.

# GNU/Linux

GNU/Linux is the term for a complete operating system composed of the Linux kernel combined with the GNU userland and system libraries. It is the most widely deployed free and open-source operating system, running on servers, desktops, embedded devices and the overwhelming majority of cloud and container infrastructure.

For a system administrator, GNU/Linux provides a mature, scriptable environment with a powerful kernel, standard Unix tools and a huge ecosystem of services. Its open-source licence means the code is fully auditable and under community control.

## Notes for administrators

- The Linux kernel is developed and maintained by a worldwide community and released under the GPLv2 licence.
- Distributions assemble the kernel and userland into ready-to-use systems with their own package managers.
- Because containers share the host kernel, GNU/Linux is the natural base for container and virtualisation platforms.

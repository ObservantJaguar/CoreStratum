# FreeRTOS

FreeRTOS is a market-leading open-source real-time operating system for embedded devices. It provides a small, deterministic kernel with task scheduling, queues, semaphores and timers, designed to run on microcontrollers with very limited resources.

Its permissive MIT license and ecosystem (including a kernel and IoT libraries) make it the default choice for many embedded projects.

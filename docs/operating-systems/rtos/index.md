# RTOS

A real-time operating system (RTOS) guarantees deterministic response times to events, making it suitable for embedded systems, industrial control, robotics and other latency-sensitive workloads where bounded scheduling is required.

This category covers open-source real-time operating systems and real-time capabilities of general-purpose kernels for administrators and engineers working at the edge.

- [FreeRTOS](freertos.md) — market-leading embedded real-time kernel.
- [Zephyr](zephyr.md) — scalable RTOS for connected devices.
- [RTEMS](rtems.md) — real-time executive for safety-critical systems.

# RTEMS

RTEMS (Real-Time Executive for Multiprocessor Systems) is a mature open-source real-time operating system designed for deeply embedded and safety-critical systems. It provides a deterministic kernel, POSIX API support and scalability from single-board computers to multiprocessor systems.

RTEMS is used in aerospace, defense, telecom and industrial applications.

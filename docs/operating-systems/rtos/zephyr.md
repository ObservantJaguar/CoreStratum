# Zephyr

Zephyr is a scalable real-time operating system (RTOS) for connected, resource-constrained devices. It supports multiple architectures and boasts a rich set of subsystems: Bluetooth, networking, sensors, USB and more, all under the Linux Foundation.

Zephyr emphasizes security and connectivity, making it popular for IoT and embedded applications.

# Windows Server

Windows Server is the server edition of Microsoft Windows. Unlike the open-source operating systems covered elsewhere in this domain, Windows Server is a proprietary product, but it is an important part of many heterogeneous environments.

This category covers Windows Server topics as they relate to an open infrastructure: interoperability with Linux and Windows services, directory and management integrations, and coexistence patterns. Specific product pages are added here as they are documented.

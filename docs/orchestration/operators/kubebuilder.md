# Kubebuilder

Kubebuilder is a framework for building Kubernetes applications and operators using the controller-runtime Go libraries and Kubernetes-style APIs. It scaffolds the full project layout, generates CRD manifests and controllers, and provides scaffolding, code generation, and testing helpers for the operator pattern.

Official site: <https://kubebuilder.io>

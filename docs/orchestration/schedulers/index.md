# Cluster Schedulers

A cluster scheduler places workloads onto the nodes of a computer cluster and manages their lifecycle, scaling and failover. It decides where a container or job runs based on resource availability, policies and constraints, keeping a cluster healthy and optimally used.

Schedulers are the control plane of container orchestration: they track the desired state of the cluster and continuously reconcile the actual state toward it.

# K3s

K3s is a lightweight, fully conformant distribution of Kubernetes certified by the CNCF. It packages the Kubernetes control plane and runtime into a small, single-binary distribution designed to run with modest resource requirements.

K3s is intended for edge computing, IoT, small servers and development environments where the full Kubernetes footprint is undesirable, while remaining compatible with the standard Kubernetes API and tooling.

## Notes for administrators

- A single binary plus a small footprint, ideal for constrained hardware.
- Package management and installation are simplified compared to full Kubernetes.
- Suitable as a quick way to stand up a real Kubernetes cluster on a single node.

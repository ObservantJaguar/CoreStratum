# Kubernetes

Kubernetes (K8s) is an open-source container orchestration platform that automates the deployment, scaling, management and self-healing of containerised applications across a cluster of nodes. It is the de-facto industry standard for running production workloads at scale.

Kubernetes provides a declarative model in which you describe the desired state, and the control plane continuously works to make the actual state match it, handling scheduling, load balancing, rolling updates and failure recovery.

## Notes for administrators

- Declarative API built around the etcd-backed control plane.
- Runs on many cloud and on-premises infrastructures, and on top of runtimes such as containerd.
- Extensible through controllers, operators, custom resources and the service mesh ecosystem.

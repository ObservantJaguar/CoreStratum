# Cilium

Cilium is a networking and security solution for Kubernetes built on eBPF, offering a service mesh that avoids sidecars entirely. Its identity-aware network policies, transparent encryption, and eBPF-based L3/L4/L7 filtering scale efficiently while uncovering traffic with deep observability.

Official site: <https://cilium.io>

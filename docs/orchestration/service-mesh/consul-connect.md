# Consul Connect

Consul Connect provides service-to-service authorization and encrypted, mutually authenticated connections on top of Consul's service discovery and configuration catalog. It offers both native sidecar integration and transparent proxies, and its service mesh features are transparent to the application with automatic mTLS through the Consul mesh.

Official site: <https://www.consul.io/docs/connect>

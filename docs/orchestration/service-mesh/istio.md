# Istio

Istio is a widely adopted open-source service mesh that provides traffic management, security, and observability for Kubernetes workloads. It injects Envoy sidecar proxies into every pod, and its control plane (istiod) handles routing rules, mTLS, authorization policies, and telemetry collection.

Official site: <https://istio.io>

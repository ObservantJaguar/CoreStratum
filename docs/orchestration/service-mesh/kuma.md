# Kuma

Kuma is a modern, multi-platform service mesh built on top of Envoy with support for both Kubernetes and VM-based workloads. Its policy-driven configuration, mTLS, and multi-zone federation make it suitable for hybrid and multi-cloud deployments, and it provides an easy-to-use UI for managing mesh configuration.

Official site: <https://kuma.io>

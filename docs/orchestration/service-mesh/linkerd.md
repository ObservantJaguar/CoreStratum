# Linkerd

Linkerd is a lightweight, ultra-lean service mesh built for Kubernetes with a strong focus on simplicity and operational safety. It uses the Rust-based Linkerd2-proxy sidecars and a minimal control plane, delivering mTLS, reliability features like retries and timeouts, and golden-metric telemetry with low resource overhead.

Official site: <https://linkerd.io>

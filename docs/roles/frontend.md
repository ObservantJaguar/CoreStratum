# Frontend Developer

The Frontend Developer builds the user interface of web applications: what runs in the browser - HTML, CSS and JavaScript, usually through a framework. The role focuses on UX, interaction, performance in the browser and integration with backend APIs.

## Job duties

1. Turn designs into interactive UI components ([UI and layout](#ui-and-layout)).
2. Implement client-side logic and state management ([Client-side logic](#client-side-logic)).
3. Secure API integration with the backend ([APIs and data fetching](#apis-and-data-fetching)).
4. Optimize page performance, accessibility and responsiveness ([Performance and quality](#performance-and-quality)).
5. Write unit/E2E tests for the UI ([Testing](#testing)).

## Responsibility domains

### UI and layout

- Languages: [JavaScript/TypeScript](../development/programming-languages/javascript.md), HTML, CSS.
- Frameworks (community, open source): React, Vue, Svelte, Angular.

### Client-side logic

- State management, routing, component libraries.
- Build tooling: Vite, Webpack, esbuild.

### APIs and data fetching

- HTTP/REST, GraphQL, WebSocket.
- [HTTP and related protocols](../foundations/protocols/index.md).

### Performance and quality

- [Playwright](../development/testing/playwright.md), [Cypress](../development/testing/cypress.md), [Selenium](../development/testing/selenium.md).
- [SonarQube](../development/analysis/sonarqube.md) for static analysis.

### Version control

- [Git](../development/version-control/git.md), [GitLab CE](../development/version-control/gitlab.md), [Gitea](../development/version-control/gitea.md).

## Out of scope

- Server-side business logic (backend).
- Database design and migrations (backend/DBA).
- Infrastructure operations (DevOps).

## Career path

- **Frontend → Senior Frontend** — design systems, performance, mentoring.
- **Frontend → Fullstack** — add backend skills (Node.js, databases).
- **Frontend → UX/Design Engineering** — specialized design/tech hybrid.

# Fullstack Developer

The Fullstack Developer works across the whole application: frontend (UI) and backend (logic, APIs, data) in a single role. In small teams this is the default "one developer builds the product" position; in large teams it usually means competence in both areas with a deeper focus on one side.

## Job duties

1. Build the user interface and client-side interactions ([Frontend](#frontend)).
2. Implement server-side logic and APIs ([Backend](#backend)).
3. Model and query data ([Databases](#databases-and-storage)).
4. Integrate services and message brokers ([Integration](#integration-and-messaging)).
5. Deploy and run the application in collaboration with DevOps ([Delivery and operations](#delivery-and-operations)).

## Responsibility domains

### Frontend

- [JavaScript/TypeScript](../development/programming-languages/javascript.md), HTML, CSS.
- Frameworks: React, Vue, Svelte, Angular.
- [Playwright/Cypress/Selenium](../development/testing/cypress.md) for UI tests.

### Backend

- [Python](../development/programming-languages/python.md), [Go](../development/programming-languages/go.md), [Java](../development/programming-languages/index.md), Node.js.
- Frameworks: Django/FastAPI, Spring Boot, Express/NestJS.

### APIs and web

- REST, GraphQL; [HTTP](../foundations/protocols/index.md).
- [Nginx](../communications/web/nginx.md), [HAProxy](../communications/web/haproxy.md).

### Databases and storage

- [PostgreSQL](../databases/relational/postgresql.md), [MySQL/MariaDB](../databases/relational/mariadb.md).
- [Redis](../databases/nosql/redis.md), [MongoDB](../databases/nosql/mongodb.md).

### Integration and messaging

- [RabbitMQ](../message-brokers/rabbitmq.md), [Kafka](../message-brokers/kafka.md).

### Delivery and operations

- [Git](../development/version-control/git.md), [GitLab CE](../development/version-control/gitlab.md).
- Containers: [Docker](../containers/container-engines/docker.md) (basics).
- [CI/CD](../orchestration/gitops/argo-cd.md) (basics).

## Out of scope

- Deep infrastructure engineering (DevOps/SRE).
- Full database administration (DBA).
- Formal UX research (design).

## Career path

- **Fullstack → Senior Fullstack** — end-to-end ownership of a product domain.
- **Fullstack → Backend/Frontend specialization** — deeper focus as the team grows.
- **Fullstack → Tech Lead** — architectural ownership.

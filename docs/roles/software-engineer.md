# Software Engineer

The Software Engineer develops, tests and maintains software products. This is the umbrella role for anyone writing production code; specialized variants are listed separately (Frontend, Backend, Fullstack) plus language-focused specializations such as Python or Java developers.

## Job duties

1. Design, implement and maintain application features ([Development](#development)).
2. Write and review code with peers (code review).
3. Test changes at unit and integration level ([Testing](#testing)).
4. Integrate with databases, APIs and external services ([Databases](#databases), [APIs and services](#apis-and-services)).
5. Work with source control and CI/CD environments ([Version control](#version-control)).
6. Debug and fix production issues ([Debugging](#debugging)).

## Responsibility domains

### Development

- Languages: [Python](../development/programming-languages/python.md), [Go](../development/programming-languages/go.md), [C/C++](../development/programming-languages/cpp.md), [Rust](../development/programming-languages/rust.md), [Java](../development/programming-languages/index.md), [JavaScript/TypeScript](../development/programming-languages/javascript.md).
- IDEs/editors: [VS Code](../development/workspace/vscode.md), [Neovim](../development/workspace/neovim.md), [Emacs](../development/workspace/emacs.md).
- Debuggers: [GDB](../development/debugging/gdb.md), [Valgrind](../development/debugging/valgrind.md).

### Version control

- [Git](../development/version-control/git.md), [GitLab CE](../development/version-control/gitlab.md), [GitHub/Gitea](../development/version-control/gitea.md), [LazyGit](../development/version-control/lazygit.md).

### Testing

- Frameworks and E2E: [Selenium](../development/testing/selenium.md), [Cypress](../development/testing/cypress.md), [Playwright](../development/testing/playwright.md).
- Static analysis: [SonarQube](../development/analysis/sonarqube.md).

### Databases

- Relational: [PostgreSQL](../databases/relational/postgresql.md), [MySQL/MariaDB](../databases/relational/mariadb.md).
- NoSQL: [Redis](../databases/nosql/redis.md), [MongoDB](../databases/nosql/mongodb.md).

### APIs and services

- Web servers/proxies: [Nginx](../communications/web/nginx.md), [HAProxy](../communications/web/haproxy.md).
- Message brokers: [RabbitMQ](../message-brokers/rabbitmq.md), [Kafka](../message-brokers/kafka.md).

## Out of scope

- Operating servers and infrastructure (sysadmin/DevOps).
- Security program ownership (SecOps).
- Network design (network engineer).

## Career path

- **Software Engineer → Senior/Lead** — architecture, mentoring, system design.
- **Software Engineer → Staff/Principal** — cross-team technical leadership.
- **Software Engineer → DevOps/Platform** — when you move into infrastructure tooling.

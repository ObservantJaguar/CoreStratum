# Authentication

Authentication platforms centralize identity, single sign-on (SSO), and access management across applications. This category covers self-hosted identity providers supporting industry-standard protocols such as OIDC and SAML for securing web services and APIs.

- [Keycloak](keycloak.md) — access management and SSO system (OIDC, SAML).
- [Authentik](authentik.md) — authentication platform with application protection.

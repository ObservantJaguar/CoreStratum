# Geli

Geli is a block-level disk encryption system in the FreeBSD operating system. It encrypts disk subsystems using the geli kernel module, providing on-the-fly encryption, multiple key support, and integration with the GELI framework for whole-disk and partition-level protection.

Official handbook: <https://docs.freebsd.org/en/books/handbook/disks/#disks-encrypting>

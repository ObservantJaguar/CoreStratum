# Cryptography

Cryptography covers technologies for protecting information at rest, signing documents, and encrypting disk subsystems. This category documents disk encryption standards and OpenPGP implementations across Linux and BSD operating systems.

- [LUKS](luks.md) — standard for Linux disk partition encryption.
- [GnuPG](gnupg.md) — implementation of the OpenPGP standard for encryption and signing.
- [Geli](geli.md) — block-level disk encryption system in FreeBSD.

# Directory Services

Directory services provide centralized identity, authentication, and policy management for domain environments. This category covers integrated identity management platforms and LDAP/Active Directory implementations used to organize users, groups, and access controls.

- [FreeIPA](freeipa.md) — integrated identity management for Linux.
- [Samba 4](samba4.md) — implementation of Microsoft AD protocols for Linux/Unix.
- [Univention Corporate Server](univention.md) — Debian-based platform for AD domains.
- [Zentyal Server](zentyal.md) — AD management based on Ubuntu.
- [LLDAP](lldap.md) — simplified LDAP implementation for small teams.

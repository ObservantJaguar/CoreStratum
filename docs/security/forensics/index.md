# Forensics

Digital forensics covers the acquisition, preservation, and analysis of data from compromised or seized systems. This category documents disk imaging, memory analysis, log reconstruction, and evidence-handling tools. Related DFIR workflows build on tools such as KAPE for evidence collection and plaso for timeline and log parsing.

- [The Sleuth Kit](sleuth-kit.md) — command-line suite for filesystem forensic analysis, with the Autopsy GUI.
- [Foremost](foremost.md) — file-carving tool for recovering files from raw images.
- [Volatility](volatility.md) — memory forensics framework for analyzing RAM dumps.
- [Guymager](guymager.md) — forensic disk imaging tool with hash verification.

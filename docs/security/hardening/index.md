# Hardening

System hardening covers mechanisms for enforcing mandatory access control, delegating privileged operations, and auditing system security. This category documents tools that reduce the attack surface and strengthen the security posture of Unix-like systems.

- [SELinux](selinux.md) — mandatory access control (MAC) for the RHEL stack.
- [AppArmor](apparmor.md) — profile-based security system for Debian/Ubuntu.
- [Sudo](sudo.md) — program for delegating superuser privileges.
- [Doas](doas.md) — minimal alternative to sudo from OpenBSD.
- [Lynis](lynis.md) — utility for deep security auditing of Unix systems.

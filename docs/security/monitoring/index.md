# Security Monitoring

Security monitoring covers platforms for detecting intrusions, collecting security events, and scanning for vulnerabilities across hosts, containers, and infrastructure. This category documents host-based IDS solutions and modern vulnerability scanners.

- [Wazuh](wazuh.md) — security monitoring and intrusion detection platform (HIDS).
- [Trivy](trivy.md) — vulnerability scanner for containers, filesystems, and IaC.

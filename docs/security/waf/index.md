# Web Application Firewall

Web application firewalls (WAF) protect web services, APIs, and microservices from attacks such as SQL injection and cross-site scripting. This category covers WAF modules, API protection platforms, and authentication portals placed in front of reverse proxies.

- [ModSecurity](modsecurity.md) — classic WAF module protecting against SQLi and XSS.
- [Wallarm](wallarm.md) — modern solution for API and microservice protection.
- [Authelia](authelia.md) — two-factor authentication portal before a reverse proxy.

# ModSecurity

ModSecurity is a classic open-source Web Application Firewall (WAF) engine that inspects HTTP traffic and applies rules to block attacks such as SQL injection and cross-site scripting. It integrates with major web servers and ships with the Core Rule Set for out-of-the-box protection.

Official repository: <https://github.com/owasp-modsecurity/ModSecurity>

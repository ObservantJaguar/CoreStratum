# Duplicati

Duplicati is an open-source backup client that stores encrypted, incremental backups to many destinations: local folders, network shares, FTP servers and cloud storage. It runs as a small local service with a web-based management UI, supports scheduling, deduplication and AES-256 encryption.

It is popular for simple, script-free backups of workstations and small servers to NAS or cloud targets.

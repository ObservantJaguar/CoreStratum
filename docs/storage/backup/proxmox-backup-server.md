# Proxmox Backup Server

Proxmox Backup Server is a backup solution designed for Proxmox Virtual Environment, optimizing the backup of virtual machines and containers. It features deduplication, compression, encryption, delta sync, and a web-based management interface for efficient data protection.

Official documentation: <https://pbs.proxmox.com>

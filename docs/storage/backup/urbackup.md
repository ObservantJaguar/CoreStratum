# UrBackup

UrBackup is an open-source client/server backup system for Linux and Windows. It offers both file-level and full image backups, with a web-based administration interface, deduplication, compression and client auto-discovery.

It is a practical choice for small and medium environments that need centrally managed backups of mixed Windows/Linux machines without a commercial license.

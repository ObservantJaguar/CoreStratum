# Block Storage

Block storage presents raw volumes (LUNs) that are formatted and mounted by operating systems, providing low-latency access for databases and applications. Standard access paths include iSCSI, Fibre Channel (FC), and NVMe over Fabrics (NVMe-oF), along with software-defined block storage platforms built on top of ordinary disks.

- [targetcli](targetcli.md) — iSCSI target management for Linux using the LIO framework.
- [FreeBSD ctld](ctld.md) — iSCSI target daemon on FreeBSD.
- [DRBD](drbd.md) — replicated block device for high-availability Linux clusters.
- [LVM](lvm.md) — flexible logical volume management on Linux.

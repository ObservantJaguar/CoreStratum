# Distributed Storage

Distributed storage aggregates resources from multiple nodes into fault-tolerant clusters, providing block, file, and object storage at scale. This category covers software-defined storage platforms used for building resilient, horizontally scalable storage infrastructure.

- [Ceph](ceph.md) — industrial distributed storage platform (block, file, object).
- [MinIO](minio.md) — high-performance object storage compatible with the Amazon S3 API.
- [Longhorn](longhorn.md) — cloud-native block storage with high availability for Kubernetes.
- [GlusterFS](glusterfs.md) — scalable network filesystem for aggregating disk resources.

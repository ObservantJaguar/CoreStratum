# Network Filesystems

Network filesystems let hosts access files on remote servers over the network as if they were local. This category covers the program implementations of network file-access protocols: the NFS protocol stack, SMB/CIFS via Samba, and SSHFS over the SSH/SFTP transport.

- [NFS](nfs.md) — network filesystem protocol implementation for Unix/Linux.
- [SMB/CIFS (Samba)](samba.md) — SMB protocol implementation for file and printer sharing.
- [SSHFS](sshfs.md) — mount a remote directory over SSH/SFTP via FUSE.

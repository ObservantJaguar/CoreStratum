# Object Storage

Object storage manages data as discrete objects with metadata and unique identifiers, providing highly scalable, S3-compatible storage for unstructured data. It covers object storage servers, buckets, versioning, and lifecycle policies. The legacy Riak CS, an early S3-compatible object store, is now largely of historical interest.

- [MinIO](../distributed/minio.md) — high-performance, S3-compatible object storage (covered under Distributed Storage).
- [Ceph RGW](../distributed/ceph.md) — the object gateway of the Ceph distributed storage platform.
- [SeaweedFS](seaweedfs.md) — fast, scalable distributed object storage with an S3-compatible API.
- [OpenStack Swift](swift.md) — the object storage component of OpenStack.
- [Garage](garage.md) — lightweight self-hosted object storage for small deployments.

# Amazon Web Services

Amazon Web Services (AWS) is the largest public cloud, providing on-demand compute through services such as EC2, along with storage, networking, and thousands of managed services at global scale. AWS is built on proprietary infrastructure and is not open source, though it implements many open standards.

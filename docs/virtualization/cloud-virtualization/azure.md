# Microsoft Azure

Microsoft Azure is a public cloud platform offering virtual machines, containers, databases, and AI services across a global network of regions. Azure runs on proprietary Microsoft infrastructure and is not open source, though it supports many open standards and open-source workloads.

**License:** Proprietary — not open source

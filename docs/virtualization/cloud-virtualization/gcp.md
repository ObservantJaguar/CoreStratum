# Google Cloud

Google Cloud Platform (GCP) delivers on-demand compute, storage, data, and machine-learning services on Google's infrastructure. It is a proprietary public cloud, not open source, although it exposes open APIs and hosts large amounts of open-source software.

**License:** Proprietary — not open source

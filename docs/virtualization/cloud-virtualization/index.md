# Cloud Virtualization

Cloud virtualisation refers to the rendering of compute, storage and networking infrastructure as on-demand, internet-accessible services. The largest public clouds — Amazon Web Services, Microsoft Azure and Google Cloud Platform — are proprietary offerings built on hypervisor and virtualisation technologies at massive scale.

While those public clouds are not open source, they implement many open standards and host open-source software, and open-source alternatives defined on top of commodity hardware exist. The detail of these proprietary providers and their relationship to open infrastructure is documented here. Enterprise virtualization is also served by platforms such as VMware (proprietary) and Proxmox (open source).

- [Amazon Web Services](aws.md) — the largest proprietary public cloud.
- [Microsoft Azure](azure.md) — Microsoft's proprietary public cloud.
- [Google Cloud](gcp.md) — Google's proprietary public cloud.
- [OpenStack](openstack.md) — the open-source (Apache-2.0) alternative for building cloud infrastructure.

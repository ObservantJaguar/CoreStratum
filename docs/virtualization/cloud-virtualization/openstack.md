# OpenStack

OpenStack is an open-source cloud platform that builds private and public infrastructure-as-a-service on commodity hardware. It provides compute, storage, and networking services with an API-driven model similar to major public clouds, making it the primary open-source alternative to AWS, Azure, and GCP.

**License:** Open source (Apache-2.0)

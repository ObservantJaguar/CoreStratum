# Hosted Virtualization

Hosted (type-2) virtualisation runs a hypervisor as an application on top of an existing operating system, in contrast to a bare-metal hypervisor embedded in the hardware layer. Guest operating systems run as user-space processes of the host OS.

This category covers open-source hosted virtualisation products that make it easy to run and manage virtual machines from a desktop or a general-purpose server operating system.

- [VirtualBox](virtualbox.md) — free, open-source type-2 hypervisor for the desktop.
- [QEMU](../hypervisors/qemu.md) — generic machine emulator that also runs in user-space (covered under Hypervisors).
- [Multipass](multipass.md) — on-demand Ubuntu VM provisioning from the command line.
- [virt-manager](virt-manager.md) — libvirt-based GUI for managing virtual machines.

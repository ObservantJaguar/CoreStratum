# VirtualBox

VirtualBox is a free, open-source hypervisor for x86 and AMD64/Intel64 virtualization. It runs as a type-2 hypervisor on Windows, Linux, macOS, and other hosts, providing an approachable interface for running and managing virtual machines with support for snapshots and shared folders.

# Operating Systems Catalog

The Operating Systems catalog contains server‑class operating systems used in infrastructure, DevOps, platform engineering, and distributed systems.

This section is organized into open OS families.  
Each entry links to a dedicated catalog with reference materials, architecture notes, configuration guidelines, and operational practices.

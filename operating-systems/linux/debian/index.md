# Debian Family Catalog

The Debian Family catalog contains Debian‑based server‑class Linux distributions used in infrastructure, DevOps, SRE, platform engineering, and cloud environments.

This section is organized into core Debian systems, production‑relevant derivatives, and specialized infrastructure distributions.

---

## Core Systems

- **[Debian](debian.md)** — foundational base system, stable release model, APT ecosystem.

---

## Production‑Relevant Derivatives

- **[Ubuntu Server](ubuntu-server.md)** — widely used in cloud and container‑native environments.
- **[Linux Mint Debian Edition (LMDE)](lmde.md)** — Debian‑based stable desktop/server variant (only Debian‑based Mint, no Ubuntu‑based Mint).
- **[Devuan](devuan.md)** — systemd‑free Debian fork for specialized infrastructure.
- **[MX Linux](mx-linux.md)** — lightweight Debian Stable derivative used in small server deployments.
- **[Kali Linux](kali.md)** — security and penetration‑testing distribution (infrastructure‑relevant).

---

## Specialized Infrastructure Systems

- **[Raspberry Pi OS](raspberry-pi-os.md)** — Debian‑based ARM server systems for SBC infrastructure.
- **[Tails](tails.md)** — privacy‑focused live system (security‑relevant).
- **[Parrot OS](parrot.md)** — security, research, and development platform.
- **[PureOS](pureos.md)** — FSF‑endorsed fully free Debian derivative.

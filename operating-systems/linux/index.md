# Linux Operating Systems Catalog

The Linux catalog contains server‑class Linux distributions and core Linux subsystems used in infrastructure, DevOps, SRE, and platform engineering.

This section is organized into major distribution families and a minimal set of independent systems that are widely used in production environments.

---

## Distribution Families

- **[Debian Family](debian/index.md)** — APT ecosystem, stable release model, server‑class distributions.
- **[Red Hat Family](redhat/index.md)** — RPM ecosystem, enterprise platforms, cloud and datacenter systems.

---

## Independent Distributions (Production‑Relevant)

- **[Alpine Linux](independent/alpine/index.md)** — musl libc, security‑focused minimalism, widely used in containers.
- **[NixOS](independent/nixos/index.md)** — declarative configuration, reproducible systems, infrastructure‑as‑code.

## Purpose

This catalog provides a structured reference for:

- Linux server administration  
- DevOps and SRE workflows  
- infrastructure and platform engineering  
- cloud and container‑native environments  

It focuses exclusively on **production‑relevant Linux distributions**.

# CoreStratum — Encyclopedia of Open Technologies

**CoreStratum** is a structured encyclopedia of open technologies, standards, protocols, data formats, hardware architectures, licenses, and the history of open‑source ecosystems.

The project is written in a unified academic style and organizes fundamental technological domains into a clean, navigable structure.

## Purpose
CoreStratum aims to provide a long‑term, academically structured knowledge base of open technologies, suitable for engineers, researchers, and enthusiasts.

## Structure
Each domain contains:
- a short description  
- structured sections  
- technology lists  
- historical notes  
- standards and specifications

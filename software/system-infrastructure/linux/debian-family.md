## Major Distributions

- **[Debian](debian.md)** — base system, APT ecosystem, release model.
- **[Ubuntu](ubuntu.md)** — LTS releases, server/desktop variants.
- **[Linux Mint](linux-mint.md)** — desktop‑oriented distribution.

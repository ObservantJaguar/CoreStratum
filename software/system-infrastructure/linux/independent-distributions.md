# Independent Distributions

This catalog contains Linux distributions that are not derived from Debian or Red Hat.  
Each entry links to a dedicated page with documentation, package management notes, configuration examples, and usage guidelines.

---

## Major Independent Systems

- **[Alpine Linux](alpine.md)** — musl‑based, security‑focused.
- **[Void Linux](void.md)** — runit init system, XBPS package manager.
- **[NixOS](nixos.md)** — declarative configuration, reproducible builds.
- **[Solus](solus.md)** — curated desktop distribution.
- **[Chimera Linux](chimera.md)** — LLVM toolchain, BSD‑style userland.
